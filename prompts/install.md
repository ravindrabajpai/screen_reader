# Installation assistant prompt

Copy the prompt below into a coding assistant with access to this checkout and the Mac where the reader will run. The actual installer remains `scripts/install.sh`.

---

Install and verify Local AI Screen Reader from this repository on my Mac.

1. Read README.md and the install, uninstall, and launcher scripts. Resolve the checkout's absolute path dynamically; never copy another user's home directory. Check applicable repository instructions. Confirm macOS, Python 3.12, and Tesseract with English language data are available. Use `./scripts/install.sh --check`; it checks prerequisites, not the full installation. If prerequisites are missing, explain them and install `python@3.12` and `tesseract` using an existing Homebrew installation within the available permissions. Do not install another package manager silently.
2. Keep this checkout at a stable location. Run `./scripts/install.sh`, which creates `.venv`, installs `requirements.lock`, verifies model checksums, and runs tests. Respect sandbox/network approval requirements. Do not use sudo, a global pip install, disable TLS, or replace pins to work around an error. Report the actual failure and fix its cause.
3. Run the installer again. Confirm it succeeds and reports both models already verified. Compare installed dependency versions and model modification times across the repeat run. Do not run install and uninstall concurrently or edit a running script.
4. If I explicitly request a clean reinstall test, stop active reading, inspect `./scripts/uninstall.sh --dry-run`, run uninstall twice, verify `.venv` and downloaded models are gone, then reinstall. Preserve unrelated files, shared system packages, and existing Shortcuts. Leave a working installation at the end. Do not remove a legacy installation until the replacement works and I have authorized the exact cleanup scope.
5. Configure existing Read Screen and Read Clipboard shortcuts in place when UI access is available. Otherwise give me the exact commands with this checkout's absolute path. Use `scripts/read.sh` and `scripts/read.sh --clipboard`, respectively, in Run Shell Script with zsh. Keep voice af_heart and speed 0.95. Preserve existing bindings unless I request changes; if missing, suggest Control+Option+R and Shift+Command+> and check for reported conflicts. Enable Quick Action and Services Menu as needed. Explain any macOS script permission prompt.
6. Ask me to test both modes using harmless text. Clipboard success does not verify screen capture. For “could not create image from rect”, inspect Screen & System Audio Recording access for the responsible launching app. Do not assume Shortcuts permission covers every invocation: macOS may attribute a keyboard-triggered run to the foreground app. Use a narrowly scoped recent permission log if needed. Never grant screen access, reset privacy permissions, or change security settings without the required user consent. Explain what the permission enables and let me complete restart prompts.
7. Summarize the install location, launch commands, bindings, checks actually passed, and remaining limitations. Do not claim live audio, OCR, or keyboard invocation passed unless observed or confirmed by me. Keep screenshots, clipboard contents, logs with personal paths, downloaded models, and `.venv` out of Git. Do not commit, push, or publish as part of installation.

The lazy background reader and progressive playback are implemented. Verify `--reader-status`, `--stop`, and `--shutdown-reader` as appropriate; describe the 30-minute default idle expiry. Offer the documented Stop Reading and Shut Down Reader Shortcut commands. Do not change code during installation or claim unmeasured latency guarantees.
